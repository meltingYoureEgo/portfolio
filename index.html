Field Notes

Small things that save real time. Each one is something I actually use — one-liners, shortcuts, and shortcuts for shortcuts.

01 — RECON

Find every subdomain in one line

Certificate transparency logs are public. Query them without any API key.

curl -s "https://crt.sh/?q=%25.target.com&output=json" | jq -r '.[].name_value' | sort -u
02 — PYTHON

Read any file as hex, find strings fast

Skip the GUI. Two lines of Python give you a strings-like output for any offset range.

data = open("sample.bin","rb").read()
print(b"".join(c if 32<=c<127 else b"." for c in data[:4096]).decode())
03 — GHIDRA

Rename every function that calls a string

Script console — auto-label based on references. Huge time saver on big binaries.

for ref in getReferencesTo(currentAddress):
    f = getFunctionContaining(ref.getFromAddress())
    if f: f.setName("ref_" + f.getName(), ghidra.program.model.symbol.SourceType.USER_DEFINED)
04 — X64DBG

Jump to OEP on any UPX binary

The ESP trick. Hardware breakpoint on the stack pointer at entry — breaks at OEP almost every time.

1. At entry, note ESP value
2. Command: "bphws esp, r, 4"
3. F9 → breakpoint hits at original entry
4. Remove breakpoint, dump memory
05 — BURP

Regex-match every UUID in responses

Proxy → Options → Match and Replace. Auto-flag every ID in the site map.

[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}
06 — BASH

Watch a log file for one pattern, live

Filter noisy output as it happens. No tail + grep + pipe gymnastics.

tail -f access.log | grep --line-buffered -E "(500|403|/admin)"
07 — LINUX

Find world-writable files in 5 seconds

Classic privilege-escalation recon. One command, useful output only.

find / -xdev -type f -perm -0002 -not -path "/proc/*" 2>/dev/null
08 — PYTHON

Decode a rolling XOR in three lines

When the obfuscation is a rolling byte key, brute the key by frequency.

from collections import Counter
c = Counter(a ^ b for a, b in zip(data, data[1:]))
key = c.most_common(1)[0][0]  # most common XOR diff = likely space/0x00
